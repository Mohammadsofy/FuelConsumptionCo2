# 🚗 Fuel Consumption & CO₂ Emissions Analysis

Analyze and model vehicle fuel consumption and CO₂ emissions using Python. The dataset includes various car specifications and their corresponding fuel usage and environmental impact.

## 🔍 Project Description
This project explores a dataset containing technical specifications of vehicles along with their fuel consumption and CO₂ emissions. The goal is to understand how different features affect fuel efficiency and environmental impact, and to build a basic predictive model using regression.

## 🛠️ Tools Used
- **Python**
- **Pandas** – for data manipulation  
- **Matplotlib / Seaborn** – for data visualization  
- **Scikit-learn** – for building and evaluating regression models

## 📂 Project Contents
- `FuelConsumptionCo2.csv`: The dataset used for analysis  
- `dataset.py`: Python script containing the data analysis and regression model code

## 📈 Analysis & Modeling Steps
1. Load and explore the dataset  
2. Visualize fuel consumption and CO₂ emissions trends  
3. Identify correlations between features (e.g., engine size, cylinders) and emissions  
4. Build a simple linear regression model to predict CO₂ emissions  
5. Evaluate the model performance

## 🧠 Key Insights
- CO₂ emissions are strongly correlated with engine size and the number of cylinders  
- Vehicles with higher fuel consumption produce more emissions  
- Simple regression models can provide a good approximation of emissions based on a few features
